## What I Learned

### External Stylesheets

- Linking a stylesheet with a link tag in the head means you write CSS once and it applies to every page that links it
- The href path has to match exactly where the file is, for example css/styles.css means the file is inside a css folder

### CSS Selectors

- Element selectors like body and h1 apply to everything of that type across the page
- ID selectors with # are unique, only one element on a page should have a given ID
- Class selectors with . are reusable across multiple elements, which is why they make more sense for things like cards and highlights
- Hover pseudo-classes let you change styling when the user moves their cursor over something, which makes nav links feel interactive

### Forms

- The action attribute tells the form where to send the data when submitted
- Each input needs a matching label with a for attribute that matches the input's id
- Different input types like text, email, select, textarea, and checkbox all behave differently and serve different purposes
- The required attribute makes a field mandatory before the form can be submitted
