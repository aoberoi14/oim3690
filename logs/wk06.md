**MP2:**

All vanilla JavaScript with state held in an array and a goal object. Deployed on GitHub Pages.

## What I learned

- How to separate HTML structure from JavaScript logic. Keeping functions focused, one function to update state and a separate one to re-render the DOM, made debugging much easier than putting everything inside one event listener.
- Date math without a library is harder than I expected. Figuring out what counts as "this week" and computing a consecutive-week streak from a flat list of date strings took a lot of trial and error. I used `Date` objects and wrote helper functions for start-of-week and start-of-month.
- How SVG `stroke-dashoffset` works to animate a progress ring. You set the total circumference as `stroke-dasharray` and then change `stroke-dashoffset` to control how much of the ring is visible.
- Input validation: checking for empty fields, zero, and negative numbers before touching state. Without this the app broke in ways that were hard to trace.

## Bugs I found and fixed

- Pace displayed as `NaN` when distance was zero on an incomplete form submit. Fixed by validating before calling the pace formula.
- The streak counter was counting the current week even with no runs logged. Fixed by treating the current week as neutral unless there is at least one run in it.
- The history filter was not updating after a delete. Fixed by calling `renderHistory()` inside `deleteRun()`.
